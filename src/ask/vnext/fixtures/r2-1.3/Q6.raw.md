# 核心结论

800VDC在AI数据中心供电架构中是“值得验证与卡位”的技术方向，并非当前可确定性规模部署的替代路线。现有知识库中的内部立项信息显示，800VDC相关方案有机会在系统效率、单柜供电能力、储能一体化和成本上形成改善，但这些数据主要是规划与目标值，尚未构成量产实绩。

未来3年更宜通过锚点客户联合开发、POC和分阶段验证推进，当前结论建议维持在客户POC/样机验证阶段，通过技术、客户、标准与供应链验证后才可进入产品化阶段。

# 技术路线、机会与风险

800VDC可理解为供电母线或供电架构；整流、DC/DC、电池、服务器PSU、保护与监控等是其中的设备或使能技术，不能把层间对象直接比较。

| 路线 | 特征 | 当前判断 |
|---|---|---|
| 传统双变换UPS + 低压直流母线 | AC→整流→逆变→负载，效率约96%，直流母线约720VDC | 成熟，但在更高单柜功率和直流绿电接入场景面临限制 |
| 800V HVDC | 输出800VDC母线，电池/储能可直挂，便于支撑更高单柜功率 | 效率与密度潜力最大，但需验证负载兼容、保护、接地与标准 |
| 超级ECO/极简UPS兼容800VDC | 市电优先直供，逆变/DC补偿，可联合电池调峰，兼容800VDC | 内部路标中最先进入POC的形态；需验证长期可靠性与全工况表现 |

机会方面：

- 效率与运营成本：内部规划提出主用超级ECO模式可实现≥99%系统效率，去除整流/PFC后模块成本降低20%\~30%、系统成本约降15%。这些是规划测算值，需在真实负载曲线下验证。
- 高功率密度与占地：规划目标是支持单柜100-300kW+，800V HVDC模块规划为180kW/2U、效率98%。在AI机柜功率快速上升背景下，减少柜位和线缆是有价值的方向。
- 储能与绿电一体化：800VDC母线更适合直挂电池和直流绿电，配合能量管理系统可实现削峰填谷、调峰增容。
- 客户卡位窗口：通过互联网/IDC大客户联合开发，可提前影响供电架构选择。知识库中出现“2026年Q2起联合开发”的路标，也有锚点客户线索，但尚未体现为公开合同或量产实证。

主要风险：

1. 生态与标准成熟度不足：内部评审也判断800VDC约2030年前后普及，当前仍处早期；统一标准、设备生态和负载兼容性需外部验证。
2. 客户需求集中：可辨识的直接需求线索主要来自少数互联网客户，全球范围内多客户可复制性、区域安规与电网制式差异尚未验证。
3. 安全与可靠性：800VDC属于高压直流，电弧、接地方式、故障隔离、维护安全与传统UPS显著不同，需要保护器件、断路器和运维流程验证。
4. 路线替代与时间窗口：若标准形成慢、客户未放量，而其他母线电压或私有供电架构先跑通，则当前投入可能无法按期回收。

# 产品化验证路径

建议分三阶段推进，边验证边升级：

- 第一阶段：锚点客户联合开发与POC。客户研发代表参与关键评审，建立双周会机制；在真实AI负载下验证效率、动态响应、短路保护、电池联合供电和削峰填谷。
- 第二阶段：800V HVDC模块和系统级验证。完成与机架、电池、DC/DC、监控的联调，重点验证“单点效率”能否转化为“系统收益”。
- 第三阶段：标准、认证与规模扩展。面向第二个或第三个客户，包括海外IDC/OEM渠道，完成目标区域安规、并网、直流保护认证后，再决定规模化产品化。

# 验证Gate、主要风险与退出条件

验证Gate：

- G1 技术可行性：代表客户POC完成，实测系统效率、单柜功率、动态响应、电池切换时间、故障保护等达到内部规划值，且成本测算通过。
- G2 客户/市场可行性：除锚点客户外，至少一家全球数据中心/IDC或海外OEM客户完成需求确认或小批量POC，证明不是单客户定制。
- G3 产品化门槛：取得目标区域认证，800VDC关键物料具备供应与交付能力，运维服务流程可复制；通过后进入产品化阶段。

退出条件对应上述主要风险触发点：

- G1实测效率与密度未能超过现有传统UPS+DC/DC路线，或安全与认证成本不可接受，退回技术跟踪。
- G2无法获得第二个独立客户，或客户转向其他供电电压/私有架构，暂停产品化投入。
- 800VDC标准与生态未形成，而竞争对手路线已获得主要客户规模验证，则转做适配器/子系统或延续现有产品线。

# 证据边界与待验证项

- 800VDC是行业“趋势”的判断来自知识库内部评审意见，不是外部权威标准或市场规模数据。
- 效率99%、成本降低20%\~30%/15%、单柜100-300kW+、180kW/2U、98%等均来自内部产品规划/测算，不应视为量产实绩。
- 知识库中出现“快手-联合开发”“互联网top5客户”等线索和客户研发代表参与机制的描述；在缺乏合同、验收、订单或公开材料前，只能作为锚点客户线索，不能确认已落地或可复制。
- 公司供应链、服务、认证与交付能力未在现有材料中完整呈现，需内部核实，不能默认在验证前已具备。

待验证项：

- 800VDC服务器/GPU PSU兼容性；
- 800VDC保护器件与断路器供应；
- 极简UPS/HVDC在全生命周期和不同工作模式下的TCO；
- 全球超大规模客户的真实需求与采购窗口；
- 与其他供电电压路线的长期共存关系。
